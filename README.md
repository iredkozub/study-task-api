# Study Task Tracker API

Домашнее задание №9 по дисциплине «Разработка приложений».

## Назначение API

API предназначен для управления учебными задачами: создания, просмотра, редактирования, фильтрации и удаления.

## Эндпоинты

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/tasks` | Получение списка задач с возможностью фильтрации по статусу |
| GET | `/tasks/{id}` | Получение задачи по идентификатору |
| POST | `/tasks` | Создание задачи |
| PUT | `/tasks/{id}` | Обновление задачи |
| DELETE | `/tasks/{id}` | Удаление задачи |

## Процесс разработки

Использован подход API-first: сначала спроектирована спецификация OpenAPI 3.0.3, затем на её основе сгенерирован серверный каркас. Спецификация содержит пять HTTP-операций, параметры запросов, успешные и ошибочные ответы, а также отдельные DTO для создания, обновления и получения задач и описания ошибок.

## Использование ИИ

При выполнении задания использовался ChatGPT (GPT-6). Основной запрос к модели: «Нужно составить пошаговый план работы, а затем провести пошаговое выполнение под моим контролем» с приложением формулировки домашнего задания. Модели были переданы требования к спецификации, кодогенерации и документации. Работа выполнялась поэтапно: выбор предметной области, проектирование DTO, описание HTTP-операций, проверка спецификации и генерация кода, а также параллельый разбор необходимых теоретических понятий. Вручную создавался и заполнялся файл `api.yaml`, проверялась документация в Swagger Editor, выполнялись команды кодогенерации. Сгенерированный Python-код вручную не изменялся.

## Кодогенерация

Использовался OpenAPI Generator версии 7.27.0 с генератором `python-flask`.

Установка генератора:

`python -m pip install "openapi-generator-cli[jdk4py]"`

Проверка спецификации:

`openapi-generator-cli validate -i api.yaml`

Генерация серверного каркаса:

`openapi-generator-cli generate -i api.yaml -g python-flask -o service`

## Структура проекта

- `api.yaml` — спецификация OpenAPI.
- `service/` — автоматически сгенерированный серверный каркас на Python.
- `README.md` — описание проекта и процесса разработки.

Бизнес-логика и постоянное хранение данных не реализованы, поскольку это выходит за пределы исходной формулировки задания.
